# ⚡ 快速开始指南

## 🎯 3步开始使用

### 第1步：配置MySQL数据库（5分钟）

```sql
-- 登录MySQL
mysql -u root -p

-- 创建数据库
CREATE DATABASE amazon_sp CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户
CREATE USER 'amazon_user'@'localhost' IDENTIFIED BY '你的密码';

-- 授权
GRANT ALL PRIVILEGES ON amazon_sp.* TO 'amazon_user'@'localhost';

-- 刷新权限
FLUSH PRIVILEGES;

-- 退出
EXIT;
```

### 第2步：安装依赖（2分钟）

```bash
# 进入项目目录
cd amazon_sp_api_system

# 安装Python依赖
pip install -r requirements.txt
```

### 第3步：启动系统（1分钟）

**Linux/Mac**:
```bash
./start.sh
```

**Windows**:
```bash
start.bat
```

**手动启动**:
```bash
python main.py
```

### 第4步：配置店铺

1. 打开浏览器访问: `http://localhost:8000`
2. 点击 "➕ 添加店铺" 标签
3. 填写表单:
   - **店铺ID**: 例如 `my_store_001`
   - **店铺名称**: 例如 `我的美国店铺`
   - **Client ID**: 从Amazon Developer Console获取
   - **Client Secret**: 从Amazon Developer Console获取
   - **Refresh Token**: 通过OAuth授权获取
   - **区域**: 选择 `NA`（北美）、`EU`（欧洲）或 `FE`（远东）
   - **Marketplace IDs**: 例如 `ATVPDKIKX0DER`（美国）
4. 点击 "✅ 保存配置"

完成！✨

## 🔑 如何获取API凭证

### 1. 注册开发者账号

访问: https://developer.amazon.com/

使用您的亚马逊卖家账号登录并注册为开发者。

### 2. 创建LWA应用

1. 在Developer Console中创建 "Login with Amazon" 应用
2. 记录 **Client ID** 和 **Client Secret**

### 3. 获取Refresh Token

通过OAuth 2.0授权流程获取 **Refresh Token**

详细步骤请查看官方文档:
https://developer-docs.amazon.com/sp-api/docs/sp-api-registration

## 💡 使用提示

### 测试配置

在保存前，使用 "🔍 测试配置" 功能验证API凭证是否正确。

### 查看店铺

在 "📋 店铺列表" 中查看所有已配置的店铺。

### 编辑店铺

点击店铺卡片的 "✏️ 编辑" 按钮修改配置。

### 删除店铺

点击 "🗑️ 删除" 按钮，确认后删除店铺。

## ⚠️ 注意事项

1. **保护配置文件**: `stores_config.yaml` 包含敏感信息，不要分享
2. **API限流**: 每天执行1-2次即可，不要频繁请求
3. **数据延迟**: 销售数据有24-48小时延迟
4. **定期备份**: 备份MySQL数据库
