# 🎉 亚马逊SP API配置管理系统 - 使用说明

## 📌 系统概述

这是一个**完全可视化**的亚马逊卖家API配置管理系统，让您无需手动编辑配置文件，通过美观的Web界面即可轻松管理多个店铺的API配置。

## ✨ 核心特性

### 🎨 可视化配置界面
- **现代化UI设计** - 采用渐变色彩和卡片式布局
- **响应式设计** - 完美支持PC、平板和手机
- **实时反馈** - 操作结果即时显示

### 🏪 多店铺管理
- **无限店铺** - 支持添加任意数量的店铺
- **分区管理** - 支持北美、欧洲、远东三大区域
- **独立配置** - 每个店铺独立的API凭证

### 🔐 安全可靠
- **配置持久化** - 自动保存到YAML文件
- **密钥保护** - 敏感信息妥善存储
- **测试功能** - 保存前可测试配置有效性

## 📖 详细功能说明

### 📋 店铺列表

**功能说明**：
- 展示所有已配置的店铺
- 显示店铺状态（启用/禁用）
- 查看店铺的基本信息和配置

**每个店铺卡片显示**：
- 店铺名称和状态
- 店铺ID
- 所属区域
- Client ID（脱敏显示）
- AWS凭证状态
- Marketplace列表

**可用操作**：
- ✏️ **编辑** - 修改店铺配置
- 🗑️ **删除** - 删除店铺（需确认）

### ➕ 添加店铺

**必填字段**：

1. **店铺ID** (store_id)
   - 唯一标识符
   - 例如：`my_us_store_001`
   - 用于程序内部识别店铺

2. **店铺名称** (store_name)
   - 便于识别的名称
   - 例如：`我的美国主店铺`
   - 在界面中显示

3. **Client ID**
   - LWA应用的客户端ID
   - 格式：`amzn1.application-oa2-client.xxxxx`
   - 从Amazon Developer Console获取

4. **Client Secret**
   - LWA应用的客户端密钥
   - 保密信息，妥善保管
   - 从Amazon Developer Console获取

5. **Refresh Token**
   - 卖家授权的刷新令牌
   - 格式：`Atzr|xxxxx`
   - 通过OAuth授权流程获取

6. **区域** (region)
   - **NA** - 北美（美国、加拿大、墨西哥）
   - **EU** - 欧洲（英国、德国、法国等）
   - **FE** - 远东（日本、澳大利亚、新加坡）

**可选字段**：

7. **Marketplace IDs**
   - 店铺覆盖的市场
   - 多个ID用逗号分隔
   - 例如：`ATVPDKIKX0DER, A2EUQ1WTGCTBG2`

8. **启用状态**
   - 默认勾选
   - 可以添加但暂不启用

**AWS高级配置**（可选）：
- AWS Access Key
- AWS Secret Key
- IAM Role ARN

### 🔍 测试配置

**使用场景**：
在保存配置前，先验证API凭证是否正确

**测试步骤**：
1. 输入Client ID
2. 输入Client Secret
3. 输入Refresh Token
4. 选择区域
5. 点击"测试配置"

**测试结果**：
- ✅ **成功** - 显示绿色提示，配置有效
- ❌ **失败** - 显示红色提示，包含错误信息

### ✏️ 编辑店铺

**操作步骤**：
1. 在店铺列表中找到要编辑的店铺
2. 点击"✏️ 编辑"按钮
3. 在弹出窗口中修改配置
4. 点击"保存"

**可编辑内容**：
- 店铺名称
- Client ID
- Client Secret（留空则不修改）
- Refresh Token
- 启用状态

### 🗑️ 删除店铺

**操作步骤**：
1. 在店铺列表中找到要删除的店铺
2. 点击"🗑️ 删除"按钮
3. 在确认对话框中点击"确定"

⚠️ **注意**：删除操作不可撤销！

## 🔑 如何获取API凭证

### 步骤1：注册开发者账号

1. 访问 [Amazon Developer Console](https://developer.amazon.com/)
2. 使用亚马逊卖家账号登录
3. 完成开发者注册

### 步骤2：创建LWA应用

1. 在Developer Console中创建新应用
2. 选择"Login with Amazon"
3. 填写应用信息
4. 获取**Client ID**和**Client Secret**

### 步骤3：注册SP API应用

1. 访问卖家中心
2. 在"应用和服务"中注册应用
3. 填写应用详情和权限

### 步骤4：获取Refresh Token

1. 使用OAuth 2.0授权流程
2. 获取授权码(code)
3. 用授权码交换Refresh Token

**详细指南**：
- [SP API注册指南](https://developer-docs.amazon.com/sp-api/docs/sp-api-registration)
- [OAuth授权流程](https://developer-docs.amazon.com/sp-api/docs/website-authorization-workflow)

### 配置文件格式
```yaml

  redis_host: localhost
  redis_port: 6379
  database_url: sqlite:///sp_api_analytics.db
  log_level: INFO

stores:
  - store_id: store_001
    store_name: 美国主店铺
    client_id: amzn1.application-oa2-client.xxxxx
    client_secret: xxxxx
    refresh_token: Atzr|xxxxx
    region: NA

      - ATVPDKIKX0DER
    enabled: true
```

## ❓ 常见问题

### Q1: 启动失败怎么办？
**A**: 
1. 检查Python版本（需要3.7+）
2. 确认安装了所有依赖：`pip install -r requirements.txt`
3. 查看错误日志

### Q2: 端口8000被占用？
**A**: 
修改`main.py`中的端口号：
```python
uvicorn.run(app, host="0.0.0.0", port=8888)  # 改为8888
```

### Q3: 配置保存后不生效？
**A**: 
配置会实时生效，无需重启服务

### Q4: 如何迁移配置？
**A**: 
复制`stores_config.yaml`文件到新环境即可

### Q5: 忘记了Client Secret？
**A**: 
需要在Amazon Developer Console重新生成

### Q6: Refresh Token过期？
**A**: 
需要重新进行OAuth授权获取新的Refresh Token

## 🎓 进阶使用

### 通过API管理配置

除了Web界面，您也可以通过API直接管理配置：

```bash
# 获取所有店铺
curl http://localhost:8000/api/config/stores

# 添加店铺
curl -X POST http://localhost:8000/api/config/stores \
  -H "Content-Type: application/json" \
  -d '{
    "store_id": "new_store",
    "store_name": "新店铺",
    "client_id": "xxx",
    "client_secret": "xxx",
    "refresh_token": "xxx",
    "region": "NA",
    "marketplace_ids": ["ATVPDKIKX0DER"],
    "enabled": true
  }'
```

### 集成到其他系统

配置管理器可以被其他Python程序调用：

```python
from app.config.sp_api_config import MultiStoreConfig, Region

# 初始化配置管理器
config = MultiStoreConfig()

# 获取所有启用的店铺
stores = config.get_all_stores()

# 按区域获取店铺
na_stores = config.get_stores_by_region(Region.NA)
```
