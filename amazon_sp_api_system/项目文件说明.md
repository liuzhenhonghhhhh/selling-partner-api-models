## 📄 核心文件详解

### 主程序入口

#### `main.py`
**FastAPI Web应用主程序**

功能：
- 启动FastAPI服务器
- 初始化配置管理器
- 提供Web配置界面
- 注册API路由

启动方式：
```bash
python main.py
# 访问: http://localhost:8000
```

---

### API层 (`app/api/`)

#### `routes.py`
**API路由定义**

包含的API端点：
- 配置管理: `/api/config/stores` (GET/POST/PUT/DELETE)
- 配置测试: `/api/config/test`
- 店铺查询: `/api/stores`
- 健康检查: `/health`

#### `schemas.py`
**数据模型定义**

使用Pydantic定义：
- 请求体模型
- 响应体模型
- 数据验证规则

---

### 配置层 (`app/config/`)

#### `sp_api_config.py`
**多店铺配置管理器**

核心类：
- `MultiStoreConfig` - 配置管理器
- `StoreCredentials` - 店铺凭证模型
- `Region` - 区域枚举
- `MarketplaceConfig` - 市场配置

功能：
- 从YAML加载配置
- 添加/更新/删除店铺
- 按区域查询店铺
- 保存配置到文件

---

### 核心层 (`app/core/`)

#### `sp_client.py`
**SP API基础客户端**

功能：
- LWA认证
- 获取访问令牌
- 签名API请求
- 发送HTTP请求

#### `reports_client.py`
**Reports API客户端**

支持的操作：
- 创建报告请求
- 查询报告状态
- 等待报告完成
- 下载报告文档
- 解压缩报告

支持的报告类型：
- `GET_SALES_AND_TRAFFIC_REPORT` - 销售和流量
- `GET_VENDOR_INVENTORY_REPORT` - 库存报告

---

### 数据层 (`app/models/`)

#### `mysql_models.py`
**MySQL数据库表结构定义**

定义的表：
1. `Store` - 店铺表
2. `SalesReport` - 销售报告（按日期）
3. `SalesReportByASIN` - 销售报告（按ASIN）
4. `InventoryReport` - 库存报告（汇总）
5. `InventoryReportByASIN` - 库存报告（按ASIN）
6. `ReportRequest` - 报告请求记录

#### `mysql_manager.py`
**MySQL数据库管理器**

功能：
- 数据库连接管理
- 自动创建表结构
- 会话管理
- 事务处理
- 批量操作

---

### 服务层 (`app/services/`)

#### `report_parser.py`
**报告解析器**

类：
- `SalesReportParser` - 解析销售报告
- `InventoryReportParser` - 解析库存报告

功能：
- 解析JSON格式报告
- 转换为数据库模型对象
- 处理嵌套数据结构
- 提取金额、日期等

#### `report_service.py`
**报告处理服务**

整合所有组件：
```
请求报告 → 等待完成 → 下载 → 解析 → 存储
```

提供方法：
- `process_sales_report()` - 处理单个销售报告
- `process_inventory_report()` - 处理单个库存报告
- `process_all_stores_sales()` - 批量处理销售报告
- `process_all_stores_inventory()` - 批量处理库存报告

#### `report_scheduler.py`
**定时调度器**

功能：
- 定时执行销售报告任务
- 定时执行库存报告任务
- 自定义执行时间
- 后台线程运行

使用方式：
```python
scheduler = ReportScheduler(config_manager, db_manager)
scheduler.schedule_sales_reports(time_str="02:00")
scheduler.start()
```

## 🔧 如何扩展

### 添加新的报告类型

1. 在 `app/core/reports_client.py` 的 `ReportType` 枚举中添加新类型
2. 在 `app/services/report_parser.py` 创建新的解析器类
3. 在 `app/models/mysql_models.py` 添加新的数据表
4. 在 `app/services/report_service.py` 添加处理方法

### 添加新的API端点

1. 在 `app/api/schemas.py` 定义请求/响应模型
2. 在 `app/api/routes.py` 添加路由处理函数
3. 在前端 `static/config.html` 添加相应的UI

### 自定义调度任务

1. 在 `app/services/report_scheduler.py` 添加新的调度方法
2. 使用 `schedule` 库定义执行时间
3. 在主程序中启动调度器
