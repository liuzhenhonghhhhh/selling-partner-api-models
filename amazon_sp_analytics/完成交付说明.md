## 💾 数据库表结构

### 基础表（不分表）
- `stores` - 店铺信息
- `daily_summaries` - 每日汇总
- `monitoring_snapshots` - 监控快照（每分钟保存一次）
- `alerts` - 告警记录

### 按年月分表（自动创建）
每个月自动创建3张表：

1. **订单表**: `orders_2024_01`, `orders_2024_02`, ...
   - 存储订单详细信息
   - 包含买家信息、配送地址、商品列表

2. **销售指标表**: `sales_metrics_2024_01`, `sales_metrics_2024_02`, ...
   - 存储按小时/天聚合的销售数据
   - 订单数、销售件数、销售额

3. **财务事件表**: `financial_events_2024_01`, `financial_events_2024_02`, ...
   - 存储收入、费用明细
   - 用于计算利润

## 🔍 关键特性说明

### 1. 按年月分表的实现

```python
# 自动创建当前月份的表
db_manager.create_month_tables(2024, 10)  # 创建2024年10月的表

# 自动创建日期范围内的所有表
start_date = datetime(2024, 1, 1)
end_date = datetime(2024, 12, 31)
db_manager.auto_create_tables_for_date_range(start_date, end_date)

# 获取指定月份的表并插入数据
OrderTable = db_manager.get_month_table('orders', 2024, 10)
```

### 2. 数据保存流程

```python
# 保存订单（自动按月分表）
storage_service.save_orders(orders, store_id)

# 保存销售指标（自动按月分表）
storage_service.save_sales_metrics(metrics, store_id, marketplace_id)

# 保存财务事件（自动按月分表）
storage_service.save_financial_events(events, store_id)

# 保存监控快照（不分表）
storage_service.save_monitoring_snapshot(snapshot_data)
```

### 3. 实时监控

```python
# 系统每60秒自动:
1. 采集所有店铺的最新数据
2. 计算实时指标（订单速率、收入速率等）
3. 保存到monitoring_snapshots表
4. 检查告警条件
5. 记录告警到alerts表
```

## 📈 数据查询示例

```sql
-- 查询2024年10月的所有订单
SELECT * FROM orders_2024_10 WHERE store_id = 'store_001';

-- 查询最近24小时的订单（跨月）
SELECT * FROM orders_2024_09 WHERE purchase_date >= '2024-09-30 00:00:00'
UNION ALL
SELECT * FROM orders_2024_10 WHERE purchase_date >= '2024-09-30 00:00:00';

-- 查询最新的监控快照
SELECT * FROM monitoring_snapshots ORDER BY snapshot_time DESC LIMIT 10;

-- 查询未处理的告警
SELECT * FROM alerts WHERE status = 'active' ORDER BY alert_time DESC;
```
