📌 核心功能

  ✅ 可视化配置界面 - 无需手动编辑配置文件
  ✅ 多店铺管理 - 支持管理无限数量的店铺
  ✅ 配置测试 - 保存前可测试API凭证有效性
  ✅ 实时更新 - 配置修改立即生效
  ✅ 安全可靠 - 配置文件自动持久化

🚀 快速启动（3步开始使用）

  第1步：启动系统
  ────────────────
  Linux/Mac用户:
    cd amazon_sp_analytics
    ./start.sh

  Windows用户:
    cd amazon_sp_analytics
    start.bat

  第2步：打开浏览器
  ────────────────
  访问: http://localhost:8000

  第3步：添加店铺配置
  ────────────────
  1. 点击"➕ 添加店铺"标签
  2. 填写您的API凭证
  3. 点击"✅ 保存配置"

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📖 主要功能说明

  📋 店铺列表
    • 查看所有已配置的店铺
    • 编辑店铺配置
    • 删除店铺
    • 查看店铺状态和详情

  ➕ 添加店铺
    • 填写店铺基本信息
    • 输入API凭证
    • 选择区域和Marketplace
    • 可选配置AWS凭证

  🔍 测试配置
    • 在保存前测试API凭证
    • 验证配置有效性
    • 获取即时反馈

🔑 如何获取API凭证？

  1. 访问 Amazon Developer Console
     https://developer.amazon.com/

  2. 创建LWA应用获取:
     • Client ID
     • Client Secret

  3. 通过OAuth授权获取:
     • Refresh Token

  详细步骤请查看: QUICKSTART.md

❓ 常见问题

  Q: 启动失败怎么办？
  A: 运行 python3 verify.py 检查系统状态

  Q: 如何测试配置是否正确？
  A: 使用"🔍 测试配置"功能验证API凭证

  Q: 配置文件在哪里？
  A: stores_config.yaml（自动生成）

  Q: 如何备份配置？
  A: 复制 stores_config.yaml 文件即可
